# LeetCode Hint Bot

An AI-powered coding assistant that provides smart hints for LeetCode problems without directly revealing the full solution.
The project helps users improve problem-solving skills by guiding them step-by-step using AI-generated hints.

---

## Features

* AI-generated hints for LeetCode problems
* Helps users think instead of copying solutions
* Fast and simple interface
* Supports problem understanding and logic building
* Secure API key handling using environment variables
* Beginner-friendly setup

## Project Idea

Many learners get stuck while solving coding problems and immediately search for complete solutions.
This project encourages active learning by giving hints progressively instead of exposing the final answer directly.

The bot acts like a coding mentor and helps users:

* understand patterns
* improve logic building
* learn problem-solving approaches

## Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/Vineet140607/leet-code-hint-bot.git
cd leet-code-hint-bot
```

### 2. Create Virtual Environment

```bash
python -m venv venv
```

Activate environment:

#### Windows

```bash
venv\Scripts\activate
```

#### Mac/Linux

```bash
source venv/bin/activate
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Create `.env` File

Create a `.env` file and add:

```env
GROQ_API_KEY=your_api_key_here
```

### 5. Run the Project

```bash
python app.py
```
